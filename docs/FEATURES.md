| 旧脚本 GBK 转码 | 已实现 | 显式选择 GB18030 / GBK 或 UTF-16；编码声明同步转为 UTF-8，执行前处理 BOM |
| 多文档、未保存提示 | 已实现 | 标签页、关闭确认、退出后草稿恢复 |
| 剪切、复制、粘贴、撤销、重做、全选 | 已实现 | 原生 AppKit 编辑菜单和快捷键 |

## 必须保留的能力边界

1. **Net UDP 与 REPL 是两种协议。** 当前应用没有宣称通过未公开的 Net 命令实现板载文件管理。仅连接 USB 网卡时可使用网络控制；板载脚本需要 B 串口。
2. WebREPL、单线网络 REPL、板载网络文件接口尚未实现。NB 已新增官方 Web 固件下载服务，与 REPL 无关；盒子刷写仍待实测。固件二进制中的模块名称不足以证明运行时可用；需要实机 REPL、可验证协议或厂商源码后才能继续这些部分。
3. 1.2.0 新增配置与监控：IP/端口、VID/PID、曲线、工作模式、外设信息、手动解析、重启、监控与轨迹；这些扩展需逐型号验证。厂商适配与本机视频采集也已有实现；完整三路轨迹未接通。输入屏蔽、LCD 图像等 SDK 专项尚未实现，仍非整个 kmNet SDK 的替代品。
4. 不模拟固件的 `km` 模块。上传到 NB 的脚本调用固件模块；模拟设备使用 CPython，只检验桌面端通信与文件工作流。
5. 不是所有旧 uPyCraft 板型和烧录器的逐项移植。交付范围与未完成的硬件验收都在本表和验收记录中列明，不能将本版称为“全部板型、全部厂商扩展、单线脚本已经实测完成”。

型号与更新路径见 [兼容性](COMPATIBILITY.md)，版本变化见 [更新记录](../CHANGELOG.md)。

## 1.2.0 Net 上位机补充

| 功能 | 状态与边界 |
| --- | --- |
| 外设信息读取 | GUI / CLI；校验应答长度，失败清除旧显示；NB 历史实测曾返回全零，不能确认有效外设查询 |
| IP/端口、VID/PID、Net 兼容曲线、KM/Bypass | GUI / CLI；参数为编辑草稿；收到 ACK 不冒充回读或掉电保存验收 |
| 连接后配置查询 | 自动只读查询外设；失败保留控制连接、清除旧值；固件版本、算法列表、当前曲线、阈值未知，AI 尚无已确认网络读写接口 |
| 手动解析模式 | 读原标识 → 修改两字节 → 写入 → 回读核对；本地写入不自动提交厂商 |
| 重启 | 单独明确操作；先清理监控和保持按键，重启仅发送一次并关闭连接 |
| 键鼠监控与轨迹 | 已知 20 字节前缀解码，保留附加字节；来源过滤、有界接收、状态与计数；设备位移和本程序请求终点分图；NB 已实测收到真实鼠标位移，三路来源未分离 |
| ICMP / 芯片 ID | GUI 与 CLI；ICMP 不建立 Net 控制会话，芯片 ID 为独立 UDP1752；回环验证 |
| 厂商适配与反馈 | 查询建议、应用并回读、主动提交结果；TCP 分片/截断测试通过，真实厂商服务未联系 |
| 视频采集与截图 | AVFoundation 原生设备/格式/帧率、预览/FPS、四种图像格式、左键沿截图；图像编码与触发逻辑通过，真实视频全链路待验收 |
| 人工 / 软件 / 修正三路轨迹 | **未完整实现**；须超过盒内阈值触发修正，目前未取得三路网络输出接口 |
| CLI 按键保持 | `hold HID_CODE SECONDS`；正常完成、Ctrl-C、SIGTERM 均清理 |
| Net 原工具固件按钮 | 原版只有占位提示；不能移植出不存在的刷写逻辑。NB HTTP 服务保留，Net IAP 尚未实现 |

实际验收范围见 [验证说明](VALIDATION.md)。
