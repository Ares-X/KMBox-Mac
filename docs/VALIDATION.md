# 验证说明

## 证据层级

- **代码测试**：验证编码、解析、状态和失败路径，不表示设备固件支持。
- **本机集成/GUI**：使用真实回环 UDP、PTY 及打包应用；模拟板使用 CPython，不等同于设备 MicroPython。
- **实际设备观察**：需要具体型号、固件、接线和实际 OTG 输出。ACK、传输进度或相机枚举不能代替最终行为。

## 从干净源码复现

```bash
swift test
python3 tools/verify_cli.py .build/debug/kmctl
bash scripts/build-app.sh
python3 tools/verify_cli.py dist/kmctl
codesign --verify --deep --strict "dist/KMBox Mac.app"
```

测试使用临时目录、回环端口和 PTY，不需要 `research/`、厂商固件、真实盒子或第三方 Swift 包。Python 3 标准库需可用；PTY 测试使用 `/usr/bin/python3`。这些命令应在仓库根目录运行。

可选固件传输检查：`python3 tools/verify_firmware.py dist/kmctl /path/to/official.cpio 80`。这个额外工具需要自备文件、空闲本机端口及第二个有效 IPv4 以测试地址过滤；它只在本机请求，不刷设备。通用 `swift test` 已使用合成 CPIO，不需要下载固件。
